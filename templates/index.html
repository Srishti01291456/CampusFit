About CampusFit

CampusFit is a machine-learning-based fitness behaviour analysis project designed to classify dropout-risk categories using fitness and lifestyle information. Dataset charts describe the supplied dataset. Individual recommendations are rule-based suggestions and should not be treated as medical advice.
